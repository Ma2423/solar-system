About This Project

SOLAR SYSTEM EXPLORER — 3D WEB APPLICATION

🌍 What is this app?

Solar System Explorer is an interactive 3D web application that lets users explore all 8 planets of our solar system. Users can click on each planet to zoom to it, read facts, pause and resume orbits, and toggle wireframe view. The app is built as a university assignment for the module Web 3D Applications at the University of Sussex.

🪐 How I Produced the 3D Models

All 3D models are built directly in X3D (Extensible 3D), using primitive geometry nodes:

  • Planets are represented using <sphere> nodes with varying radii proportional to real planet sizes.
  • Saturn's rings use a flat <cylinder> node with transparency applied.
  • Earth's Moon is a smaller sphere nested inside Earth's transform node.
  • Orbit paths are drawn using <circle2d> nodes rotated 90° to lie flat.
  • Each planet has its own <transform> and <timesensor> to drive orbital animation.

🎨 Design Choices

I chose a dark space aesthetic with a deep navy/black background, gold and blue accent colours, and the Orbitron and Exo 2 fonts to give a sci-fi feel. The layout uses a three-column design: planet navigation on the left, the 3D scene in the centre, and planet information on the right. Bootstrap 5 was used for the responsive grid structure.

Colour was used deliberately to differentiate planets (e.g. blue for Earth/Neptune, orange-red for Mars, golden for Saturn) matching their real-world appearances as closely as possible with X3D material colours.

♿ Accessibility Considerations

  • All buttons have descriptive text labels.
  • Colour contrast between text and backgrounds meets readability standards.
  • The layout is structured with semantic HTML5 elements.
  • Font sizes are legible and the layout avoids relying solely on colour to convey information.
  • Audio is opt-in — it only plays when the user explicitly clicks the play button.

🏗 MVC Design Pattern

The application follows an MVC (Model-View-Controller) structure:

  • Model: Planet data (names, descriptions, facts) stored in a JavaScript object in app.js, and persisted in an SQLite database accessed via PHP.
  • View: The HTML pages (index.html, about.html) and CSS (style.css) handle all presentation.
  • Controller: JavaScript functions in app.js handle user interactions (button clicks, camera movement, wireframe toggle) and update the view accordingly.

🛠 Technologies Used

HTML5 CSS3 JavaScript X3D Bootstrap 5 PHP SQLite AJAX / JSON X3DOM Google Fonts

🧪 Deeper Understanding Statement & Testing Feedback

To go beyond the lab tutorials, I implemented:

  • GLSL-style emissive glow on the Sun using X3D material emissiveColor.
  • Orbital animation using TimeSensor + OrientationInterpolator routing.
  • Saturn's ring system using a transparent cylinder primitive.
  • Dynamic camera repositioning via JavaScript when a planet is selected.
  • A PHP/SQLite API backend to serve planet data as JSON.

Testing Feedback: The app was tested by a classmate who confirmed the planet buttons correctly update the info panel and camera position. The orbit animations run smoothly. Suggested improvement: add texture images to planets for more realism.
